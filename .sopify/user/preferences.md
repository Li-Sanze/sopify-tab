# 用户长期偏好

- Sopify 是本地品牌。仓库和品牌用 Sopify Tab / `sopify-tab`，不用 SopifyT、Worktab、Startnook。
- 产品是个人也能用、也可以上架的 Chrome 新标签页工作台。
- 商店主交付是桌面：装完即可用。聊天是可选项，要另装 Host 且本机有 coding CLI。
- 工作台优先。聊天用 Side Panel，不放在新标签页 DOM 里。
- 聊天自研薄层，不引入开源聊天产品，不嵌 Multica。
- 第一版 agent 用 `cursor-agent` 的 ask 模式，只读，cwd 锁定。
- 第一版不做微信读书、天气、音乐、番茄钟、收藏夹、富文本便签。
