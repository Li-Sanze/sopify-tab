# W7 视觉简报

对照 SoT：`prototype/index.html` + `prototype/shots`。本波要的是原型那种透视深度，不是写实风景。实现锁 CSS + SVG。

## 白天

一层透视舞台，不是平涂渐变。

- **透视**：场景 `perspective`；层用 `translateZ` 推远。远云更小、更蓝、更贴地平；近云更大、更清、可出画。
- **光**：画外左上单一光源。天顶在光的反侧加深，光侧暖雾，地平发浅。
- **雾 / 气**：近地空气变厚（地平霾），不是第二套壁纸。
- **云**：远 → 近分层。积云用受光球体 + 底暗平板 + 投下的软影；边缘可用 SVG 湍流 / 置换做出绒边。禁止照片贴图。

## 夜晚

同一透视舞台，换夜层。

- **多层星野**：至少远 / 中 / 近三层。远层密而暗、透视缩小；近层疏、略暖；时钟口袋与地平处要稀，免得抢书桌。
- **银带**：一条淡的银色银河带（斜向、软、低对比），不是霓虹、不是赛博网格。
- **地平辉光**：贴地的一层气辉，把星野溶进地平，不做城市灯带。
- **#17 安静环（可选保留）**：#17 已合的远景安静椭圆环可留。环只是一层，不是主角；无行星实心球、无卡通月亮盘、无环动画。不要则仍须保住 #17 其余夜层，不得借机整页推倒。

## 禁止

- 写实照片、视频底、壁纸商店
- 粒子系统 / 闪烁垃圾（twinkle spam）
- 默认 WebGL / Canvas（本波不以此为交付路径）
- 挡时钟或玻璃模块的「英雄壁纸」
- 霓虹、赛博网格、城市剪影

默认运动 **Calm**（极慢）。`prefers-reduced-motion` → **Still**。
