## 最小视觉范围

只动 `extension/` 天空/主题 token、玻璃与间距相关。无新渲染栈。

1. **纵深（MB-③）**  
   既有 CSS `perspective` + 层语言再加深。远层更软、更雾、更贴地平；近层更清。雾/气是深度，不是第二套壁纸。
2. **玻璃（MB-①）**  
   磨砂玻璃层级再贴近日板：模块叠在天空之上可读，边缘与间距更安静。日/夜同一套层语义。
3. **间距**  
   只为纵深/玻璃可读做克制收束。不借机重开 W8 布局合同，不新开栏。
4. **夜（MB-② vibe 仅）**  
   深靛蓝 + 软光晕；抽象光带/雾。取 vibe，不复刻夜景海报。

禁止：WebGL / Canvas / 粒子；照片贴图；写实楼宇；海报式行星环；挡时钟的英雄壁纸；moodboard widget 墙。

## Still
