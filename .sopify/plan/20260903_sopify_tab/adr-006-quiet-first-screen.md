# ADR-006: 默认不连，第一屏不提 Host

## 状态
已采纳

## 上下文
演示在问候旁、左栏底和侧栏同时写「未检测到 Host」。用户对照审计后锁定：默认不连，第一屏不提 Host。没连不是故障。

## 决策
打开新标签页默认不当聊天产品。书桌不放 Host 芯片、连接灯或「未检测到」。对话按钮和工具栏入口要到 Side Panel 能真正发送时（Wave 3）才出现。设置页 Wave 2 才加，作为用户主动要连的入口。「没连 Host」只写成说明，不当成状态。

## 理由
商店包的主交付是安静书桌。把「没连上」画成缺省错误，会让没装 Host 的人以为产品坏了，也和「装完即可用」冲突。

## 替代方案
- 问候旁放开关「启用本机对话」：拒绝。第一屏仍被聊天占住。
- Wave 1 先做禁用发送的 Side Panel 壳：拒绝。安装后出现明确不可用的主入口。
- 左栏始终亮红点：拒绝。同一件事用故障语气重复。

## 影响
Wave 1 权限不含 `sidePanel`。newtab 验收不得出现 Host / CLI / 对话字样。
