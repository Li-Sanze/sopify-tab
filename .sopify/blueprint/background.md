# 蓝图背景

## 长期目标
- 打开 Chrome 新标签页先看到安静桌面和当前标签。
- 需要时从 Side Panel 对本机 Cursor CLI 做只读问答。
- 可以上架：没有 Host 时工作台仍完整可用。没连不是故障。

## 范围
- 范围内: 新标签页工作台（书桌、标签；设置后加）、当前窗口标签整理、本机扩展存储中的书桌数据、可选 native host、ask 模式聊天、稳定扩展 ID。
- 范围外: Multica 嵌入、云同步、账号系统、多 CLI 选择器、Chrome 网上应用店上架操作本身（上架是后续单独方案）。

## 非目标
- 不是本地权重 / Ollama 聊天产品。
- 不是关侧栏后仍后台跑 agent 的执行平台。
- 不是微信读书或氛围插件集合。
